6) [Expedition Supply] Research

Event Duration: 2026/11/12 10:00 - 2026/12/16, 23:00 (UTC)

Event Details: Exchange for [Expedition R&D Tickets] in the [Expedition Supply] screen. [Expedition R&D Tickets] are the exclusive Research token for the [Expedition Supply] Research Pool, and can be used to draw rewards in the [Expedition Supply] Research Pool. For specific rules, please check the Research Pool details.


-- Rewards Overview --

Core Layer Reward: S-Rank Omniframe Choice Pack x1 (up to [Selena: Pianissimo])

1st Layer Reward: 6★ Weapon Resonance Material x1, 6★ Weapon Resonance Material x1, S-Rank CUB Choice x1 (up to [Snow Waltz], recommended for [Selena: Pianissimo])

2nd Layer Reward: Trade Voucher x2,000, Phantom Pain Scar x50, Hypertune Material Pack x3, 6★ Memory Resonance Material Pick x2, Coating Blueprint x20, Cog Pack (XXL) x6

Extra Reward: A-Rank CUB Choice x1


-- Event Rules --

• Each research consumes [Expedition R&D Tickets], and the cost increases with each research. The rules are as follows:

-For the 1st to 10th research, each research consumes [Expedition R&D Tickets]: 50/200/400/600/800/1200/1600/2000/2500/3150

-You can exchange for [Expedition R&D Tickets] using Event Construct R&D Tickets or Target Weapon R&D Tickets. Both tokens can be exchanged for an equal amount of [Expedition R&D Tickets].

• All rewards are limited items and cannot be obtained again once drawn.

• Starting from the 5th draw, there is a chance to obtain the [S-Rank Omniframe Choice Pack].

• Completing 8 researches grants the Extra Reward [A-Rank CUB Choice], and completing 10 researches guarantees a Core Layer reward.

• This [Expedition Supply] Research Pool is an independent pool. It does not share guarantee count with other Construct Research Pools, and the guarantee count cannot be inherited. This Research Pool will close after the event ends, so please plan accordingly. After the event ends, any remaining [Expedition R&D Tickets] will be converted into [Basic Construct R&D Tickets] at a [1:1] ratio.

VI. Dreamscape Disequilibrium

1) Event Details

• Explore Leia's spiritual world and complete the trial of the Beauty Sefirah.

• Convert your characters and buffs into "Wish Weights," and the enemy's units and buffs into "Cost Weights." Weigh your choices on the scale to achieve mass balance.

VII. New Content & Optimizations

—— New Features & Optimizations ——

1. Added a notification popup for poor network conditions during game resource downloads.

2. After the [A Comet's Afterglow] version update, the PC version of Punishing: Gray Raven supports up to 4K resolution. Commandants using 4K display devices can select Fullscreen Mode in the Graphics Settings, as well as choose 2560×1440, 2560×1600, and 2560×2048 resolution options in Windowed Mode.

3. The opening time of the [Clash Reflection] mode will be adjusted from 5:00 to 8:00 (UTC). This change will take effect starting with the new [Clash Reflection] period on December 3, 2026. Please plan your game time accordingly.

4. Added the affixes "Frostbound Chasm V" and "Greedy Frost III" to Intensive Battle in [Phantom Pain Cage].

5. Adjusted the [War Zone] Full-Realm Support effect "Harrowing Freeze." The effect is now "Character gains a 60% Glaciation DMG Bonus for 12s after entering the battlefield."

6. Optimized the Return system (the following changes take effect after the version update on November 5, 2026. Commandants who return before then will follow the original Return system).

- Adjusted the guidance flow of the Return system.

- Adjusted the rewards of the Return system and removed some content from the old Return system.

- Optimized the system interactions and UI art of the Return Handbook.

- Added text descriptions for the [Return Event].

- Added interactive Easter eggs to the event main interface. Tap to interact.

- Added [Return Support]. During the event, returning Commandants will receive exclusive Service Missions that grant additional Service Certificates upon completion. Returning Commandants will also have a limited number of chances to earn double [Simulation Score] during the event.

 

—— Character Optimizations ——

1. Fixed an issue where [Kamui: Aeternion] could take damage while pressing and holding the Basic Attack in certain situations.

2. Fixed an issue where [Kamui: Aeternion]'s eye visuals appeared abnormal while casting Signature Move in certain situations.

3. Fixed an issue where the camera behaved abnormally if [Adelyde: Anabasis] was defeated while pressing and holding a Signal Orb.

4. Fixed an issue where Weapon Resonance effects appeared abnormally in stages after [Adelyde: Anabasis] used a Signal Orb Skill.

5. Fixed an issue where weapons left on the field by [Adelyde: Anabasis] in "Abyssfarer Form" were not recalled correctly in some cases.

6. Fixed an issue where [Karenina: Effulgence] could activate her Core Passive [Surge Breach] twice in succession in some cases.

7. Fixed an issue where interrupting a Signal Orb ping with a Dodge could cause additional Signal Orbs to be consumed when pressing and holding Basic Attack with [Rosetta: Arete] in some cases.

8. Fixed an issue where [Kurumi Tokisaki]'s QTE voice line did not play correctly.
